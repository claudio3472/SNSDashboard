# Advanced Data Visualization (MIACD) 2025/26 - Final Project

This project was developed for the Advanced Data Visualization course (MIACD) 2025/26 at the University of Coimbra. It consists of an interactive visualization application built with Plotly/Dash in Python, designed to solve analytical problems and communicate information. The visualization focuses on exploring data from the Transparency Portal (Portal da Transparência).

## Project Goals

The main goal of this visualization is to provide an interactive, multiple-view dashboard that effectively answers analytical questions regarding the national health system in Portugal. The application implements advanced visualization models and advanced interaction techniques.

## Repository Structure

This project follows a modular architecture to separate data extraction, exploratory analysis, and the final visualization:

* **`data/`**: Contains the datasets. The cleaned and ready-to-use data generated by our pipeline is located in `data/processed/`.
* **`src/`**: Source code for data preprocessing.
    * `utils.py`: Helper functions for data extraction, cleaning, and standardization.
    * `data_prep.py`: Main script that executes the data pipeline.
* **`notebooks/`**: Jupyter Notebooks used for Exploratory Data Analysis (EDA).
* **`app/`**: (Under development) Source code for the interactive Plotly/Dash dashboard.

## Prerequisites

- Python 3.9+ installed
- `pip` package manager

## Setup and Execution

**1. Clone the repository and navigate to the folder:**

```bash
git clone https://github.com/claudio3472/VAD2026.git
cd VAD2026
```

**2. Create and activate a virtual environment:**

`python -m venv venv`

On Windows:

`venv\Scripts\activate`

On Mac/Linux:

`source venv/bin/activate`

**3. Install dependencies:**

`pip install -r requirements.txt`

### How to obtain the data?
To load, clean, and standardize the data from Portal da Transparência, run the following command on the root folder:

`python src/data_prep.py`

The clean files will be stored in the folder `data/processed/`.
